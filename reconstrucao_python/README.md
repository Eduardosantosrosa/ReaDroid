# Reconstrução Python — Independent TV

Reimplementação independente baseada no comportamento documentado e nas
interfaces técnicas do Extreme InfiniTV v1.9.0.

Referência:
https://github.com/infinitel8p/Extreme-InfiniTV/tree/v1.9.0

A versão de referência é GPL-3.0-or-later. Esta reconstrução deve preservar
os avisos de licença e cumprir as obrigações da GPL caso incorpore código
derivado da implementação original.
