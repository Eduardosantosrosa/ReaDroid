# Stream Shelf

Independent Android IPTV client in package `org.independent.streambox`. It imports local M3U using Android's document picker, can query an explicitly entered Xtream-compatible host, stores a basic library/favorites locally, searches by name/category and opens media in an installed Android player.

The original APK was inspected statically only. No original images, code, endpoints, or branding are included. Xtream layouts differ across providers; current series/EPG fidelity is incomplete. The project targets Android 10 (API 29) and min API 23. For standard Android SDK installations, run `gradle :app:assembleDebug`.
